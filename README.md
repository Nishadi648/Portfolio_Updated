# HCI React Portfolio Starter

This starter is designed for a Human-Computer Interaction portfolio assignment. Personalize every placeholder before submission.

## 1. Setup

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

## 2. Customize

Edit these files first:

- `src/data/profile.js` - name, photo, education, skills, contact links, career aspirations
- `src/data/projects.js` - your three real projects, technologies, GitHub links, screenshots/live links
- `public/profile-placeholder.svg` - replace with your own photo, then update the path in `profile.js`
- `public/screenshots/` - replace placeholder SVGs with real project screenshots
- `index.html` - update the page title and meta description

## 3. HCI features already included

- User-centered structure for internship reviewers
- Clear navigation using React Router
- Active navigation feedback
- Semantic HTML elements: header, nav, main, section, article, address, footer
- Skip link for keyboard users
- Visible focus states
- Alt text for images
- Responsive layout for mobile and desktop
- Contact form success message without backend
- Consistent card, button, spacing, and typography system

## 4. Build

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## 5. Deploy options

### Netlify

- Push the project to GitHub.
- In Netlify, create a new site from Git.
- Build command: `npm run build`
- Publish directory: `dist`

### Vercel

- Push the project to GitHub.
- Import the repository in Vercel.
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

## 6. Submission reminder

Do not submit this starter unchanged. Replace all placeholder text, links, screenshots, and personal details. Add your deployed website URL to the written report.
